# KryptrixLabs™ Future Project Registry

This registry records approved future KryptrixLabs projects without reopening the completed Foundation definition of done.

## Approved Future Projects

### KRYP-BOT-001 — KryptrixLabs Bot
**Status:** APPROVED / PLANNED  
**Repository target:** `kryptrixlabs/kryptrixlabs-bot`

Purpose: build a KryptrixLabs-specific assistant grounded in the Foundation corpus and project state.

Initial v0.1 scope:
- Repository-aware retrieval over the KryptrixLabs manual, appendices, lab architecture, and project records.
- Grounded answers with source citations.
- Project-state awareness using `FINAL_PROJECT_STATUS.md` and authoritative control records.
- Navigation commands such as:
  - “Where are we?”
  - “Show the lab architecture.”
  - “What remains for KRYP-001?”
  - “Find the procedure for X.”
- Read-only GitHub integration first.
- Optional Lab Controller integration later.
- No autonomous destructive actions in v0.1.

Architectural rule: the bot is a separate product built on top of the Foundation. It must not become a blocker to Foundation closure.
